# Flexhub

A small collection of extensions for [CloudStream 3](https://github.com/recloudstream/cloudstream).

## Add repository

Open **CloudStream → Settings → Extensions → Add repository** and paste:

```
https://raw.githubusercontent.com/ethioel/Flexhub/builds/repo.json
```

Then install the extensions you want from the list. Installed extensions update automatically when a new build is published.

## Extensions

| Provider | Content |
|----------|---------|
| 1Flex    | Movies, TV, Anime |
| 1Shows   | Movies, TV |
| 1Shows Alt | Movies, TV |
| 1Tube    | Movies, TV |
| AniCine  | Anime, Movies, TV |
| 67movies | Movies, TV |
| Netshows | Movies, TV |
| CineVibe | Movies, TV |
| KaitoTV  | Movies, TV |
| CineHD   | Movies, TV |

All extensions support search, bookmarks-style home rows and multi-quality playback (default quality follows the app's player settings).
