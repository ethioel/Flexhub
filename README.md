# Flexhub

A small collection of extensions for [CloudStream 3](https://github.com/recloudstream/cloudstream).

## Add repository

Open **CloudStream → Settings → Extensions → Add repository** and paste:

```
https://raw.githubusercontent.com/ethioel/Flexhub/builds/repo.json
```

Then install the extensions you want from the list. Installed extensions update automatically when a new build is published.

If a domain goes down, its alt serves the identical catalog — install the matching provider from the list.
